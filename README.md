# High Directional & Ultra-Wideband Antenna

## 📖 Project Overview

This project focuses on the design and simulation of a **High Directional & Ultra-Wideband Antenna** operating in the **5–6 GHz frequency band**. The antenna is designed to provide high gain, wide bandwidth, and reliable communication for modern wireless applications.

## 🎯 Objectives

* Design a high-directional antenna operating at 5–6 GHz.
* Achieve gain between 12–15 dBi.
* Support 1 GHz bandwidth.
* Maintain 30° × 30° beamwidth.
* Handle up to 100W power.
* Ensure linear polarization and signal integrity.

## ⚙️ Specifications

| Parameter       | Value     |
| --------------- | --------- |
| Frequency Range | 5–6 GHz   |
| Bandwidth       | 1 GHz     |
| Gain            | 12–15 dBi |
| Beamwidth       | 30° × 30° |
| Power Handling  | 100W      |
